# 把当前会话钉成飞书投递目标

命令必须单独占据整条输入，只允许三种形式：

```bash
node '{{SCRIPT:feishu-pin-session.mjs}}'
node '{{SCRIPT:feishu-pin-session.mjs}}' --apply
node '{{SCRIPT:feishu-pin-session.mjs}}' --clear --apply
```

无参数只读查看。`--apply` 把**运行它的这条会话**钉成投递目标，`--clear --apply` 取消。

**必须在你要接收飞书消息的那条会话里运行。**它靠 session id、PID 和现场登记三者
交叉核验来认自己 —— 在别处替另一条会话钉，等于又回到猜。

## 什么时候需要它

项目级绑定在同一个项目开着多条会话时，说不清该投给哪一条，入站会**拒收**：
宁可发不进去，也不投错 —— 投不进去你当场就知道，投错了要等到「它怎么没反应」
才发现，而那时指令可能已经在另一个上下文里被执行了。

拒收回执里给的就是这条命令。现场只有一条会话时会自动认定，不用手动钉。

## 边界

它钉的是「投给哪条会话」，**不改变绑定级别**，也不新建话题。
会话级绑定本来就钉死在它绑的那条线上，对它运行会被拒绝。

把 stdout 转述给 Frank 时保留结构，不要新增脚本没说的判断。
不展示话题 id、会话 locator 等敏感标识 —— 脚本刻意只打印会话 id 的前 8 位。
